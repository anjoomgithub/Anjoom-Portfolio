# Distribution Management System

## Overview
The **Distribution Management System (DMS)** is a comprehensive full-stack solution designed to streamline the complex operations of distributors, wholesalers, and field sales teams. This platform integrates inventory management, order processing, and real-time sales tracking into a unified interface.

## Key Features
*   **Inventory Control:** Real-time stock tracking across multiple warehouses.
*   **Order Management:** Seamless processing from inquiry to delivery.
*   **Field Sales App:** Mobile-friendly interface for sales reps to punch in orders on the go.
*   **Analytics Dashboard:** Visual insights into sales performance and trends.

## Tech Stack
*   **Backend:** Django 5 (Python)
*   **Frontend:** React 19
*   **Database:** PostgreSQL
*   **Mobile:** Capacitor (for Android implementation)

## Installation
1.  Clone the repository:
    ```bash
    git clone https://github.com/Anjoom/DMS_Project.git
    ```
2.  Install backend dependencies:
    ```bash
    pip install -r requirements.txt
    ```
3.  Run the development server:
    ```bash
    python manage.py runserver
    ```
